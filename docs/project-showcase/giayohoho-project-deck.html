08 / Cart + order + coupon

Checkout tập trung vào dữ liệu đơn hàng không đổi theo thời gian

Luồng mua hàng

  • Giỏ hàng gắn tài khoản, coupon và các item theo product variant.
  • Checkout tạo `order_details`, `order_item` và snapshot sản phẩm/biến thể/ảnh.
  • Đơn hàng có idempotency key, status, payment method và thông tin GHN snapshot.
  • Khách hàng xem danh sách đơn, chi tiết đơn và hủy đơn khi còn hợp lệ.

Coupon

  • Coupon có version, usage limit, min purchase và max discount.
  • Applicable scope gồm ALL, BRAND, PRODUCT và VARIANT.
  • `account_coupons` ghi coupon đã dùng theo account/order.
  • DiscountCalculator hỗ trợ fixed, percentage và seasonal sale.

13 / Docker + vận hành

Đường chạy local được đóng gói để dựng nhanh

Docker Compose

  • `app` build Laravel + Vite assets và chạy tại cổng 8000.
  • `postgres` dùng PostgreSQL 16 với healthcheck.
  • `mailpit` phục vụ SMTP và UI xem mail tại cổng 8025.
  • Entrypoint chờ DB, migrate, seed nếu `RUN_SEEDERS=true`.

Cấu hình nhà cung cấp

  • PayOS qua `PAYOS_CLIENT_ID`, `PAYOS_API_KEY`, `PAYOS_CHECKSUM_KEY`.
  • GHN có thể bật/tắt bằng `GHN_ENABLED`, fallback local khi demo.
  • Google OAuth nhận ID token qua `/api/auth/google`.
  • Monitoring proxy tùy chọn cho Prometheus, Loki và Grafana.

14 / Kiểm thử + rủi ro

Hệ thống đã qua nhiều lớp kiểm tra, nhưng vẫn còn điểm cần xác minh thật

Đã kiểm tra

  • PHP lint các tệp đổi trong app, routes, database.
  • `php artisan route:list --path=api` đạt theo nhật ký, 186 API routes.
  • `npm run build` đạt với Vite, Docker compose config đạt.
  • HTTP smoke test từng đạt cho `/`, `/contact`, `/admin/monitoring`, `/api/health`.

Cần nhớ khi bảo vệ

  • Chưa chạy `docker compose up --build` và migrate PostgreSQL thật trong lượt nhật ký.
  • PayOS, GHN, Google OAuth cần credential thật khi chạy production.
  • CSV export tương thích Excel, chưa phải XLSX native.
  • Bundle frontend còn cảnh báo chunk chính lớn hơn 500 kB.
